# TE26 Steuerung

Handy-Steuerung für den TE26-Labyrinth-Roboter (Hochschule Darmstadt, Technischer Entwurf).
Eine Webseite, die sich per Web Bluetooth direkt mit dem Roboter verbindet (Gerätename `TE26`, Nordic-UART-Dienst).

- **Android:** in Chrome öffnen.
- **iPhone:** in der App *Bluefy* öffnen (Safari kann kein Web Bluetooth).
- Querformat. Links fahren (Strecke wählen, 90° drehen, Stopp), Mitte Live-Karte mit den 5 Abstandssensoren,
  rechts Verbindung, Akku, autonome Labyrinthfahrt und ein Feld für beliebige Befehle.

Das eigentliche Projekt (Firmware, CAD, Doku) liegt in einem privaten Repo.
